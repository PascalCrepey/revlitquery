# Check whether a candidate term matches each text in \`texts\` (case-insensitive, hyphen-flexible)

Check whether a candidate term matches each text in \`texts\`
(case-insensitive, hyphen-flexible)

## Usage

``` r
term_matches_text(term, texts)
```

## Arguments

- term:

  Single candidate term.

- texts:

  Character vector of texts.

## Value

Logical vector of length \`length(texts)\`.
