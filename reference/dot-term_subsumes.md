# Check whether term \`t_broad\` lexically subsumes \`t_narrow\` inside an OR block

Check whether term \`t_broad\` lexically subsumes \`t_narrow\` inside an
OR block

## Usage

``` r
.term_subsumes(t_broad, t_narrow)
```

## Arguments

- t_broad:

  Broader candidate term.

- t_narrow:

  Narrower candidate term.

## Value

Logical scalar.
