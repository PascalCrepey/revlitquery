# Check Google Scholar \<= 256 character constraint

Check Google Scholar \<= 256 character constraint

## Usage

``` r
is_valid_gs_query(q, max_gs_chars = 256L)
```

## Arguments

- q:

  Canonical \`search_query\` object.

- max_gs_chars:

  Maximum allowed character count (default 256).

## Value

Logical scalar.
