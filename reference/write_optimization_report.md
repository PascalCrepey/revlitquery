# Write all optimization artifacts (CSVs, Markdown report, PNG plot) to \`output_dir\`

Write all optimization artifacts (CSVs, Markdown report, PNG plot) to
\`output_dir\`

## Usage

``` r
write_optimization_report(result, output_dir = "output")
```

## Arguments

- result:

  Optimization result list from \`optimize_queries()\`.

- output_dir:

  Output directory path.

## Value

Invisibly returns list of generated file paths.
