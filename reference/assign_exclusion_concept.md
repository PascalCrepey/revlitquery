# Classify a candidate exclusion term into a scientific exclusion concept

Classify a candidate exclusion term into a scientific exclusion concept

## Usage

``` r
assign_exclusion_concept(term)
```

## Arguments

- term:

  Single candidate exclusion term (may end with \`\*\`).

## Value

One of \`"competing_subtypes"\`, \`"experimental_lab"\`,
\`"vaccines_immunology"\`, \`"veterinary_ecology"\`, or
\`"general_noise"\`.
