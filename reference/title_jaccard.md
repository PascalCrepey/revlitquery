# Compute alphanumeric lowercase token Jaccard similarity between two titles

Compute alphanumeric lowercase token Jaccard similarity between two
titles

## Usage

``` r
title_jaccard(t1, t2)
```

## Arguments

- t1:

  First title string.

- t2:

  Second title string.

## Value

Numeric Jaccard similarity in \`\[0, 1\]\`.
