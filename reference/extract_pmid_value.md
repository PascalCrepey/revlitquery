# Extract a PubMed ID (PMID) from explicit fields or URL/note text

Extract a PubMed ID (PMID) from explicit fields or URL/note text

## Usage

``` r
extract_pmid_value(pmid_field = "", url_field = "", note_field = "")
```

## Arguments

- pmid_field:

  Explicit pmid/pubmedid field.

- url_field:

  Optional url field.

- note_field:

  Optional note field.

## Value

Character scalar (digits or "").
